# How to setup node modules

## Windows

事前に node.exe に PATH を通す。

### Chromium Edge がすでにインストールされている場合

環境によって、Chromium のダウンロードに失敗します。そのため、PUPPETEER_SKIP_DOWNLOAD を指定して Puppeteer のインストールを実施します。

**エラーの例**

```text
npm error ERROR: Failed to set up Chromium r1108766! Set "PUPPETEER_SKIP_DOWNLOAD" env variable to skip download.
```

**インストール方法**

```text
cd {projectFolder}/bin
SET PUPPETEER_SKIP_DOWNLOAD=1  # コマンドプロンプトの場合
$env:PUPPETEER_SKIP_DOWNLOAD=1 # PowerShell の場合
npm install
```

### Puppeteer に Chromium をダウンロードさせる場合

以下のコマンドがエラー無く完了する環境の場合は、以下の方法でも良い。  
一般的に企業内環境では失敗することが多いため、「Chromium Edge がすでにインストールされている場合」によること。

```text
cd {projectFolder}/bin
npm ci
```

## Linux

Chromium の依存ライブラリが多数存在するため、Puppeteer に Chromium をダウンロードさせる場合でも依存関係の解決に留意してください。  
過去バージョンの Chromium が `.cache/puppeteer/chrome` に残ることがあるので、適宜過去バージョンは整理するとよい。

```text
cd {projectFolder}/bin
npm install
```

### pub_markdown_core.sh で外部 Chrome を使用する場合

`PUPPETEER_EXECUTABLE_PATH` に実行可能な Chrome を指定すると、`pub_markdown_core.sh` は Puppeteer 用の Chrome をダウンロードせず、指定された Chrome を使用します。  
`PUPPETEER_SKIP_DOWNLOAD` だけを指定した場合や、`PUPPETEER_EXECUTABLE_PATH` が実行できないファイルを指す場合は、環境変数を指定しない場合と同じく `$HOME/.cache/puppeteer` へ Chrome をダウンロードします。

```bash
export PUPPETEER_EXECUTABLE_PATH=/usr/local/bin/chrome
export PUPPETEER_SKIP_DOWNLOAD=true
bash bin/pub_markdown_core.sh --workspaceFolder="$PWD"
```

`PUPPETEER_EXECUTABLE_PATH` は `pub_markdown_core.sh` の実行中に検証されます。  
無効なパスは警告を表示せず、スクリプトのプロセス内で未指定として扱います。  
呼び出し元シェルの環境変数は変更されません。
