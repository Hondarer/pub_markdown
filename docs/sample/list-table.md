# 箇条書きの項目に入れる表

Pandoc と MkDocs の両方で表を箇条書きの項目の中に入れるには、項目の本文と表の間に空行を置き、表を 4 スペース単位で字下げします。  
トップレベルの項目は 4 スペース、1 段ネストした子項目は 8 スペースです。  
表題は、表の直後に空行を置き、表と同じ字下げで `Table:` 行を記述します。

## 子項目は 8 スペースで表を入れる

親項目のマーカーは行頭に置き、子項目のマーカーは 4 スペースにします。  
子項目の中の表は、そこからさらに 4 スペース下げて 8 スペースにします。
