# 日本語技術文書の作成と推敲

1. `framework/docsfw/docs/japanese-technical-writing-guideline.md` を読んでください。
2. 対象文書の読者、目的、正本としての役割を確認してください。
3. 一段落一論点、一文一行、本文のです・ます調を適用してください。
4. 重複する説明を正本へ集約し、入口文書はリンクへ置き換えてください。
5. 用語、因果、条件、文書間の整合性を確認してください。
6. `text_style_jp.py --dry-run` を実行し、不自然な機械変換がないことを確認してください。
7. 問題がなければ `--in-place` を実行し、差分を読み直してください。

翻訳や UI 表記を扱う場合は `understand-japanese-docs-style` も使用してください。
